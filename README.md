# TeamFinder

Платформа для поиска команды и управления pet-проектами. Пользователи могут регистрироваться, заполнять профиль, добавлять навыки, публиковать проекты и присоединяться к командам других участников.

Текущая реализация использует **вариант 2**: навыки пользователей и фильтрация участников по навыкам.

## Реализация: допущения

- В задании связь `User.skills` описана как «внешний ключ на Skill», но реализована как `ManyToManyField`: у пользователя может быть несколько навыков, а одним навыком может владеть много пользователей — это необходимо для фильтрации участников по навыкам. Имя обратной связи совпадает с заданием: `skill.users`.
- Поле `User.phone` в модели сделано необязательным (`default=""`), потому что форма регистрации из задания не содержит телефон. Уникальность непустых номеров обеспечена ограничением в БД и валидацией формы, при сохранении номера нормализуются к формату `+7XXXXXXXXXX`.

## Технологии

- Python 3.11
- Django 5.2
- PostgreSQL 16
- Docker и Docker Compose

## Запуск

1. Создайте файл окружения:

   ```bash
   cp .env_example .env
   ```

2. Запустите PostgreSQL и Django:

   ```bash
   docker compose up --build --wait -d
   ```

   Миграции выполняются автоматически при запуске `web`, а флаг `--wait` дожидается готовности приложения. Оно доступно по адресу http://localhost:8000. PostgreSQL опубликован на хостовом порту `5436`, чтобы не конфликтовать с другими локальными базами.

3. На чистой базе загрузите демонстрационные данные:

   ```bash
   docker compose exec web python manage.py loaddata \
     fixtures/skills.json fixtures/users.json fixtures/projects.json
   ```

   Fixtures создают трёх пользователей, по одному проекту от каждого пользователя и связанные с профилями навыки.

## Администрирование

Панель администратора находится по адресу http://localhost:8000/admin/.

Создание суперпользователя:

```bash
docker compose exec web python manage.py createsuperuser
```

## Тесты

Запуск всех тестов на PostgreSQL в Docker:

```bash
docker compose exec -T -e DJANGO_TEST_POSTGRES=1 web \
  python manage.py test users projects --settings=team_finder.test_settings
```

Для локального запуска тестов на SQLite установите зависимости в виртуальное окружение и выполните:

```bash
python manage.py test users projects --settings=team_finder.test_settings
```

## Основные адреса

- `/projects/list/` — список проектов;
- `/users/list/` — участники и фильтр по навыкам;
- `/users/register/` — регистрация;
- `/users/login/` — вход;
- `/users/skills/?q=...` — автодополнение навыков;
- `/users/<id>/skills/add/` — добавление навыка владельцем профиля;
- `/users/<id>/skills/<skill_id>/remove/` — удаление навыка из профиля.

## Структура

- `users/` — пользователи, аутентификация, навыки и формы профиля;
- `projects/` — проекты, участники и статусы;
- `fixtures/` — демонстрационные данные;
- `templates_var2/` — шаблоны текущего варианта;
- `static/` — CSS, JavaScript, шрифты и изображения;
- `team_finder/` — настройки и корневые маршруты Django.
